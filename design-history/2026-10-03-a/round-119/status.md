# 第 119 轮：统一卡片间距——**已实现，尚未送评**

## 用户反馈

「卡片之间的间距都不协调」——这次是**可测的具体反馈**。

## 实测（改前）

| 相邻两块 | 间距 |
| --- | --- |
| 字标 → 名字行 → 两栏 | 5 ／ 4（两个不同的值） |
| **两栏 → 共同时间** | **0（贴死）** |
| 共同时间 → 留言 | 14 |
| 留言 → 底栏 | 144 |

另外**名字行的左边缘是 22，卡片是 38——差 16px 没对齐**。

## 本轮改动（一处）

把首页所有相邻块的间距统一为 14px、左右统一为 16px，并把名字行的左边缘对齐到与卡片相同的位置。

## 实测（改后）

| 项 | 改后 |
| --- | --- |
| 四个左边缘 | **38 / 38 / 38 / 38** ✓ 全部对齐 |
| 字标 → 名字行 | 14 ✓ |
| **名字行 → 两栏** | **4（盒）≈ 9（视觉）——未统一** |
| 两栏 → 共同时间 | 14 ✓（原为 0） |
| 共同时间 → 留言 | 14 ✓ |
| 留言 → 底栏 | 144（不是卡片间距，是内容未填满屏） |

无横向溢出、无纵向滚动、无运行错误。

## 未完成的一处（如实记录）

**「名字行 → 两栏」的间距没能改成 14。** 我把两栏的上边距从 9 依次调到 19，实测该处仍为 4（盒）——说明**还有一条我尚未定位的规则在控制这个值**（可能是 `.home-thesis` 的负边距、或 `.time-pair` 上一条同权重但源序更后的规则）。

这一处**留待下一轮**：先用浏览器逐条列出命中 `.time-pair` 的 `margin-top` 规则，再改。

## 另一个已知问题（不属于「卡片间距」）

「留言 → 底栏」是 144px 的空白，不是间距不一致，而是**内容没有填满屏幕**。要处理得另开一轮（例如让留言卡吸收剩余高度，或调整整屏的纵向分布）。
