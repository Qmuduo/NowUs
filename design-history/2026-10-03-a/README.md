# 2026-10-03-a · 首页三个版面方向（用户要求重新设计）

## 起因

用户连续三次反馈：配色不喜欢 → 配色不高级 → 太暖、想要时尚杂志 → **「页面可以重新设计吗？我觉得不好看」**。

**换了两轮配色都没解决，说明问题不在颜色，在版面。** 这一屏的骨架自第 88 轮起未变：标题行 → 两个钟 → 分隔线 → 共同时间块 → 分隔线 → 留言 → 底栏，是一个普通 App 的堆叠列表。

## 三个方向（`layout-options.html`）

| 方向 | 结构 | 关键差别 |
| --- | --- | --- |
| 1 · 封面式 | 两人状态各占**通栏**、上下叠放，白底 / 黑底，70px 衬线数字 | 强调「先后」；通栏才让昼夜对比真正铺满 |
| 2 · 版式网格 | 左窄栏标签 / 右宽栏内容，只用**发丝线**，无任何填充块 | 最克制、最像杂志内页；昼夜降为 7px 圆点，对比变弱 |
| 3 · 对开式 | 左右两栏**等高对开**（白 / 黑），共同时间做成**横跨两栏**的通栏带 | 强调「同时」；用版面表达「同一段时间属于两个人」 |

三版都用真实数据（阿远 08:00 纽约 / 我 20:00 北京 / 可联系 10:00–10:30、22:00–22:30 / 阿远 15 分钟前的留言），底色统一中性白 `#FAFAF8`、文字近黑 `#0E0E0E`，昼夜只靠明暗。

## 说明

本目录是**设计探索**，不修改 `prototype/`。选定方向后再进 `prototype/` 并按协议送评。
