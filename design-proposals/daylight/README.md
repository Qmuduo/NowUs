# NowUs · 两地天光 / 相接的我们

2026-10-03，独立交互设计提案 v4.1。

## 本版改进

- 首页、时间轴、双方作息与下一次共同窗口共用 `schedule.js` 的计算结果。编辑工作日或休息日偏好、设置临时状态后，两处同步更新。
- 临时状态有明确恢复时间，演示时钟随页面打开后的时间推进；到期恢复通常偏好，页面每 30 秒刷新。
- 按日期选择工作日或休息日模板；未知、暂停、未配对和未来七天无交集分别处理。联系窗口详情会定位到对应日期与时段。
- 便签草稿自动保存在本浏览器；关闭后可继续。空白和超过 120 个字符拒绝提交。删除有确认及持续可见的撤销入口；打开弹层时清除可能遮挡按钮的提示。
- 解除演示配对后进入个人首页，不再显示伙伴时间、便签或双人时间轴。自己的日常安排保留。
- 新品牌采用相接的 n/u 曲线：夜蓝、晨光与共用的青色一笔。应用图标、完整字标、彩色/单色/反白标记及 19 个界面图标已接入并导出。

## 页面

三个主入口：此刻 / 一天 / 留话。头像进入个人节奏、分享控制与品牌设计。首页便签前置，时间信息作为生活背景；活动来源与联系意愿保持独立。

便签使用纸张、胶带、横线、折角和楷体署名。所有效果由本地 CSS 与 SVG 实现，无远程图片和字体依赖。时间轴以真实时长排列，联系意愿单独用细条叠加。

## 范围

仍是本地交互设计稿，使用北京、纽约及 2026-10-03 的示例账号与时间起点，没有真实账号、消息发送或后端连接。临时状态只改变演示资料。除便签草稿外，表单、配对状态与已保存便签在刷新后恢复样例。

时间引擎用于设计稿联动校验，正式应用应接入既有产品时间引擎和权限接口。资料编辑页仍是只读版式示例；离线重试只模拟恢复连接。短于 30 分钟的自定义事件会保持比例，可通过附近视图和活动详情查看。

现有 Android 与原 prototype 的实现不属于此目录交付范围。

## 验证

时间模型覆盖双方交集、编辑联动、临时状态排除与到期、未知/暂停/未配对、跨日及工作日模板。浏览器检查包括留言草稿恢复、误删撤销、配对空状态、桌面及窄屏；具体证据见 `verification-v4.md`。
