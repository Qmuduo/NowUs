# NowUs 原型验证记录

日期：2026-09-29。范围：静态交互原型，按已批准的产品定位与视觉方向制作。

## 已验证

- Node 内置测试共 6 项通过：跨时区日期、当地一天的边界、默认共同窗口、没有交集、临时忙碌缩短窗口、午夜睡眠。
- HTML 页面在浏览器正常加载，JavaScript 语法检查通过，浏览器无错误或警告日志。
- 320×640、375×812、414×896 三种手机尺寸没有横向溢出或页面整体滚动，底部导航可见，按钮触控高度不小于 44px；桌面有独立手机框与场景入口。
- 时间轴双列按真实时刻对齐，活动块没有文字溢出，滚动时保留双方城市标签。
- 四种演示场景展示不同当地日期、无共同窗口与带到期时间的主动状态。
- 留言支持保存、空内容校验、编辑、删除及撤销；输入的 HTML 标记作为普通文字显示。
- 临时忙碌会排除原本的共同窗口，联系窗口详情展示双方日期和时段。
- 弹窗打开后焦点进入弹窗，Shift+Tab 可到关闭按钮，Escape 关闭后焦点回到入口。
- 提醒有保存反馈，并明确说明不会发送通知。
- Finesse 检查无 P0 阻断项。设计 stamp 在外部样式表中；检查器对 HTML / JavaScript 单文件仍报告缺少 stamp 的 P2 提示。

## 验证限制与当前范围

CSS 与 JavaScript 都包含减少动画的分支；当前浏览器未提供系统减少动画偏好的模拟能力，因此未做该偏好的运行时切换验证。

作息、城市和时间使用演示数据；没有账号、配对、真实同步、通知权限或日程编辑。留言仅保存在当前浏览器，共同窗口根据独立的联系偏好估计，不能代表已约定的通话。

首页及时间轴预览保存在 `prototype/preview-home.png` 与 `prototype/preview-day.png`。完整交互请通过本地 HTTP 服务体验。
