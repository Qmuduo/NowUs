# NowUs 原型验证记录

日期：2026-09-29。范围：静态交互原型，按已批准的产品定位与视觉方向制作。

## 已验证

- Node 内置测试共 6 项通过：跨时区日期、当地一天的边界、默认共同窗口、没有交集、临时忙碌缩短窗口、午夜睡眠。
- HTML 页面在浏览器正常加载，JavaScript 语法检查通过，浏览器无错误或警告日志。
- 320×640、375×812、414×896 三种手机尺寸没有横向溢出或页面整体滚动，底部导航可见，按钮触控高度不小于 44px；桌面有独立手机框与场景入口。
- 时间轴双列按真实时刻对齐，活动块没有文字溢出，滚动时保留双方城市标签。
- 四种演示场景展示不同当地日期、无共同窗口与带到期时间的主动状态。
- 留言支持保存、空内容校验、编辑、删除及撤销；输入的 HTML 标记作为普通文字显示。
- 临时忙碌会排除原本的共同窗口，联系窗口详情展示双方日期和时段。
- 弹窗打开后焦点进入弹窗，Shift+Tab 可到关闭按钮，Escape 关闭后焦点回到入口。
- 提醒有保存反馈，并明确说明不会发送通知。
- Finesse 检查无 P0 阻断项。设计 stamp 在外部样式表中；检查器对 HTML / JavaScript 单文件仍报告缺少 stamp 的 P2 提示。

## 验证限制与当前范围

CSS 与 JavaScript 都包含减少动画的分支；当前浏览器未提供系统减少动画偏好的模拟能力，因此未做该偏好的运行时切换验证。

作息、城市和时间使用演示数据；没有账号、配对、真实同步、通知权限或日程编辑。留言仅保存在当前浏览器，共同窗口根据独立的联系偏好估计，不能代表已约定的通话。

首页及时间轴预览保存在 `prototype/preview-home.png` 与 `prototype/preview-day.png`。完整交互请通过本地 HTTP 服务体验。

## 第二轮迭代验证

以下记录对应 V2，替代上文第一轮的功能范围和测试数量。

- 11 项时间模型测试通过，新增独立连续活动、缺失资料、次日窗口、工作日／休息日配置、跨午夜联系区间与睡眠冲突验证。
- 首页缩小时间面板，对方的短留言预览在生活阶段后出现；展开后可查看全文和发布时双方时间。
- 时间轴默认展示当前日期内最多六小时，可切换全天及回到此刻；独立活动保持连续，共同窗口单独呈现。全天高度为 4032px，通常场景附近范围为 756px。
- 浏览器确认上课活动详情显示“10:00–10:30 可联系”，同时说明活动与联系偏好独立，不将设置等同实时空闲。
- “我的节奏”测试：工作从 06:00 开始与睡眠冲突时拒绝保存；把联系区间改为 22:15–22:30 后，窗口变为北京 22:15–22:30／纽约 10:15–10:30，刷新后保留。
- 两套模板均选择暂不设置联系偏好时，显示未知与设置入口，不生成虚假窗口。随后恢复默认模板时间，避免遗留冲突或缺失测试值。
- 五种场景已验证，日期不同场景保留 9月30日／9月29日；没有当日交集时可显示未来窗口；伙伴未设置时明确说明暂不能推荐。
- 320×640、375×812、414×896 检查三个页面，没有横向溢出或页面整体滚动，按钮触控宽高均不小于 44px。
- 发现半小时活动块裁切后，调整为紧凑显示，三种宽度复查无活动文字溢出。更短活动保持比例，通过单独的详情入口查看。
- JavaScript 语法检查、浏览器错误／警告日志和 Git 空白检查通过。Finesse 无 P0/P1，外部 CSS stamp 的单文件 P2 提示仍保留。
- 保存三张新版预览：首页、时间轴与 `prototype/preview-rhythm.png`。
- 另验证十分钟活动的单独详情入口可用；未细分活动来源为“未知”。为第二版资源添加版本参数后，两份浏览器预览都确认加载了更新后的来源标记。

仍无后台、配对、真实发送和通知。周一至周五／周末模板、同日主要活动与一段联系区间是这一轮的简化边界；伙伴不可代改。减少动画的运行时验证限制沿用第一轮记录。
