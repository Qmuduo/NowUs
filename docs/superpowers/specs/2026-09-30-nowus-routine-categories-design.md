# NowUs 作息类别与时间轴配色设计

日期：2026-09-30。

## 目标

让作息覆盖更广的日常活动，并通过跨页面一致的类别颜色提升时间轴区分度。具体时段仍可自定义名称与时间；颜色由明确的类别字段决定，不从用户填写的标签文字猜测。

## 类别

作息时段提供以下类别：睡眠、起床准备、用餐、通勤、学习／工作、休息／午睡、运动、家务／办事、社交／娱乐、其他。未安排空档继续显示为“未安排”，不自动补成某类活动。运动、家务／办事和社交／娱乐可通过添加时段选择；学生与上班族模板不替用户虚构这些个人习惯。

学生和上班族模板默认包括睡眠、起床准备、早餐、通勤、学习／工作、午餐、午间休息、返程通勤和晚餐；休息日提供睡眠、起床准备、早餐、午餐、自由安排和晚餐。自由安排按“其他”显示；模板不把自由时间假设为社交、运动或家务。现有具体钟点仍是可编辑建议，不表示某座城市的大多数人的实际时间。

## 数据与兼容

- `RoutineBlock` 增加稳定枚举类别并随作息 JSON 同步。
- 旧数据中缺少 `category` 的时段解码为“其他”；不更改或推断用户填写的活动名称。
- 服务端接受旧客户端省略类别的请求，并校验新客户端提供的类别。数据保存在既有 JSONB 字段，无数据库迁移。
- “未安排”是由空档计算出的展示类别，不作为可保存时段类别。

## 颜色与可访问性

编辑器类别选择器和双方时间轴使用同一组柔和底色：睡眠靛蓝、起床准备暖沙、用餐琥珀、通勤青绿、学习／工作蓝、休息薰衣草、运动珊瑚、生活事务鼠尾草绿、社交粉紫、其他灰绿、未安排浅灰。

活动标签和类别名称继续显示，深色文字放在浅色背景上；颜色只用于辅助区分，不单独承载活动含义。双方相同类别使用相同颜色，共同联系窗口仍保持独立的绿色标记。

## 验收

- 模板为默认块分配正确类别，并加入起床准备时段。
- 用户可以在不改时段名称的情况下修改类别；保存后本机和账号同步均保留类别。
- 时间轴中的己方与伴侣分段都按类别显示一致颜色；空档保持中性灰色。
- 旧 JSON 和旧 API 客户端继续可用；非法类别被服务端拒绝。
- 单元测试、后端 Docker 测试和实体手机模板编辑流程通过。
