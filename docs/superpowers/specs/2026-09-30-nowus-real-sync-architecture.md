# NowUs 真实账号同步架构选择

日期：2026-09-30。起点：`5034765`。目标：以可在本地运行的服务实现邮箱 OTP、双账号配对和受控同步；部署区域与实际跨境网络表现仍待真实环境验证。

## 方案比较

| 方案 | 大陆与海外可达性如何验证 | 邮箱 OTP | 原子配对与逐用户授权 | 开发与维护 |
| --- | --- | --- | --- | --- |
| Supabase Auth + Postgres/RLS + RPC | 需在选定区域、真实大陆与海外网络上测登录、邮件和 API；管理控制台可选区域不等于网络验证 | 托管 OTP；生产邮件需配置 SMTP | RLS 限制行访问，数据库函数可在事务中接受邀请 | 本地 Supabase CLI 依赖 Docker；生产需账号、项目和邮件凭据 |
| Firebase Auth + Firestore | 同样需实测目标网络、邮件和 API | 邮箱登录能力可用，但自定义六位 OTP 与邀请流程需额外服务逻辑 | Security Rules / transaction 可实现，但需额外协调资料关系 | 托管运维较少；本地 Emulator Suite 可运行，产品逻辑仍需 Cloud Functions |
| 自托管 FastAPI + PostgreSQL + Mailpit（选择） | 单一 API 地址可放在候选地域逐项实测；本地 Docker 只验证功能，不证明跨境可达 | 服务端生成六位随机 OTP、限流、过期和一次使用；本地投递至 Mailpit；生产用环境变量配置 SMTP | Postgres 事务、唯一成员约束和服务端身份校验；API 每次读取按当前配对与分享状态授权 | 一个 Compose 命令启动 API、数据库和收件箱；Python/Postgres 常见工具，保留 SQL 迁移与 API 集成测试 |

## 已选实现

- **Android**：沿用 Kotlin + Jetpack Compose 和既有 `TimeEngine`。本地体验数据与真实账号分开；不把模拟伴侣、演示邀请码或演示作息上传。
- **认证**：邮箱 + 六位 OTP。服务端使用密码学随机值；10 分钟到期、60 秒重发间隔、按邮箱与来源限流、错误尝试上限、成功后立即作废。会话为随机不透明令牌，数据库只保存摘要，Android 使用 Android Keystore 加密保存令牌。
- **服务与数据库**：FastAPI 单体 API + PostgreSQL 18，SQL 迁移逐次执行。接受邀请在一个事务中锁定邀请并写入一对成员；数据库唯一约束确保每个账号最多一个关系。
- **邮件**：开发使用 Mailpit 的 SMTP sink 与网页收件箱。真实发送以 SMTP 环境变量接入；未配置时开发服务仍可本地运行，生产配置不完整时拒绝启动。
- **授权**：所有资料、作息、临时联系状态和留言写入都从已验证会话确定所有者；禁止客户端指定所有者 ID。读取伴侣数据必须有当前有效关系且双方都在分享。暂停或解除后 API 立即停止返回对方资料；客户端前台刷新周期 30 秒并在恢复前台时刷新。
- **邀请**：邀请码可手动输入，也生成 `nowus://invite/{code}` App 链接。链接不是认证凭据；预览仅返回邀请人昵称、城市与固定共享范围，登录后保留待处理邀请码，接收前再次预览并明确接受。
- **过渡**：体验版继续作为单独入口。真实账号设置提供导入本机“本人昵称、城市、作息和当前留言”的确认步骤；不导入伴侣、演示邀请或模拟对方信息。

## 真实网络与发布边界

本地 Docker / API 测试只证明实现逻辑和本地 SMTP sink 可用。此仓库没有云服务项目、已选地域、域名和真实 SMTP 凭据，因此不声称大陆与海外均可达，也不声称 QQ、163、Gmail 或 Outlook 邮件已送达。上线前必须用实际部署地址、真实大陆网络与首批海外所在地分别测试登录、邀请和同步，并检查多邮箱提供商的收件与垃圾箱情况。单机 Compose 是开发环境，不作为生产 HA 或备份方案。
