# NowUs 首次使用与配对原型

状态：用户已同意补齐首次使用与配对流程，并整理真实 MVP 清单和验收标准。

## 范围与设计

保留浅绿页面、昼夜双色时间卡、44px 触控与底部操作。入口位于“演示”及桌面评审侧栏，既有示例双人首页保持可访问。

1. 选择昵称和城市：提供少量真实时区的城市，城市选择实际决定当地时间。昵称必填，最多 20 个字符，不使用定位。
2. 设置自己的节奏：复用工作日／休息日模板，支持保存前校验。可暂不设置联系偏好；保存后进入等待邀请状态。
3. 邀请伴侣：展示本地演示邀请，支持查看邀请接收页、撤销后重建、稍后邀请。不会复制分享链接或对外发送。演示邀请有效期 24 小时。
4. 确认配对：接收页展示邀请方身份、分享内容和接受／返回操作。接受后展示双方昵称与城市；对方作息仍未知。可另外模拟对方填好示例作息，再进入对照首页。

## 关键状态

- 等待加入：只显示自己的真实当地时间和设置，不显示虚构的对方日期、活动、留言或共同窗口。
- 已加入但未设置：可显示对方已选择城市的当地时间，活动和联系时间保持未知。
- 资料齐全：使用明确标注的模拟伙伴作息演示对照，仍不产生虚构留言。
- 邀请失效、撤销或已被接受：阻止再次接受，并提供返回邀请页的路径。
- 返回已有原型：引导可退出；已保存的本地设置可继续。首次使用的演示记录与原先示例留言分开保存。

## 验证与交付

对邀请状态转换、城市／昵称校验写纯函数测试。浏览器验证完整路线、稍后邀请、未填写作息、保存恢复与窄屏。真实账号、真实邀请、后端同步和平台选择留到下一阶段；本次另交付明确的 MVP 验收清单。
