# NowUs 原型第二轮

状态：用户已授权按上一轮六项评审建议修改，保留已批准的 Finesse 视觉方向。

## 设计范围

- 首页压缩双时钟，突出生活阶段，并在生活卡片下显示对方留言预览；留言预览可展开全文和写留言。
- 联系窗口使用“按双方联系偏好”“尚未约定”，不把设置等同于实时空闲。忙碌活动内的联系设置单独说明。
- 时间轴默认显示当前日期内的附近六小时，可展开全天。双方活动独立连续，同一位置依然是同一时刻；共同窗口以跨列底色和独立提示表达。日期、双方标签、切换范围与回到此刻入口位于同一固定工具区。
- 新增“我的节奏”页面，工作日与休息日分别设置睡眠、工作／上课和一段愿意联系时间；支持跨午夜睡眠和联系区间，主要活动采用同日时段。保存前验证冲突，保存后更新首页与时间轴，仅保存在本地。
- 未细分的活动显示“未细分安排”，未填写的联系偏好保持未知。主动愿意联系与活动类别分别表达。
- 今天无交集时搜索接下来七天；若资料缺失，说明暂不能推荐。保留留言入口，增加缺失资料演示场景。

## 交付边界

仍为固定人物和时间的静态原型。伙伴资料是演示数据，只有自己的节奏可编辑。没有后台、真实通知、配对或对外发送。减少动画、键盘与手机安全区规则沿用。
