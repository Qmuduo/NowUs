## 3. 必须忠实还原的视觉系统

整体保持安静、温暖、清晰的生活感：夜蓝与晨光的双人时钟、前置的纸质便签、青色联系提示、舒展留白和细圆角线条。不要变回通用后台卡片、默认 Material 组件堆叠或大面积高饱和情侣主题。

从最终 CSS 提取颜色、字号层级、行距、间距、圆角、阴影、描边、图标尺寸和状态规则，建立 Compose design tokens 与复用组件。主要页面色值包括：

- 背景 `#F5F7FA`，表面 `#FCFDFD`。
- 正文 `#25364A`，辅助文字 `#657381`，分隔线 `#DCE3E7`。
- 夜色 `#2D425D`，日光卡片 `#F9E5C9`。
- 联系青 `#246B65`，浅青底 `#E7F0EC`。

品牌色另有晨光 `#EFC88F` 与纸白 `#F5F1DF`。不要把不同用途的相近色合并成一个颜色。便签纸色、胶带透明度、折角与横线以实际 CSS 为准。

字体需保留普通 UI、清晰时间数字、便签正文及手写署名之间的层次。Windows 字体名称不能直接当 Android 可用字体；使用合法可分发字体或可靠的本地替代，实际核对中文、标点、数字与换行。核心视觉不能依赖运行时网络下载。

按同等逻辑尺寸对照还原，适配屏幕与系统字体缩放；不要机械地把所有 CSS px 当作 sp。正式 Android 使用真实系统状态栏、导航栏、安全区和键盘避让，不复制网页的假手机外框、假电池、假时间、手势条、左右设计注解与演示情境下拉框。

## 4. 页面与交互要求

### 此刻

- 顶部为新 Logo、“我的状态”和个人设置入口。
- 依次呈现简短问候、双方身份、并排的当地时钟、活动来源与时差、对方便签、共同联系窗口。保持 v4.1 的信息优先级和空间关系。
- 两侧卡片显示真实城市、身份、当地时间、日期、星期和通常活动；昼夜色彩按各自当地时间变化。
- 对方留言必须是首页的重要内容，点按进入完整便签。不能降级成一行聊天预览。
- 联系窗口显示双方当地起止时间、必要日期和剩余/开始时间，注明“按联系偏好估计，尚未约定”。详情解释来源，并可定位到一天里的对应日期与时段。
- 临时状态支持愿意联系、暂不方便、跟随通常偏好，持续时间为 30 分钟、1 小时、3 小时；明确到期时间并自动恢复。
- 问候、昵称、城市、时差方向和时间必须来自真实数据，不能固定成“你的夜晚，他的早晨”、北京快 12 小时或样例人物。

### 一天

- 保持双列、同一时间轴的结构。同一高度对应同一实际时刻，活动高度按真实时长显示。
- 联系意愿用独立绿色细条表示，不因联系窗口变化把持续活动切碎；不能把通常活动误写成实时状态。
- 提供前后日期、附近几小时、我的当地全天、回到今天；说明刻度属于谁的当地时间，双方日期与跨日标识清楚。
- 活动详情展示完整时间、信息来源和独立联系偏好。短活动仍能读取和操作，不能为了点击面积破坏时间比例。
- 查看非今天时说明这是按当前模板预览，不是实际历史记录。此刻指示线只在对应日期和可见范围内显示。

### 留话

- 对方留言是一张有设计感的便签：柔和纸色、半透明胶带、细横线、轻微纸张阴影、折角、收件人、署名、发送地时间与相对时间。保留当前克制的纸张质感，不做聊天气泡，也不要自行堆叠装饰。
- 对方便签为主，自己的便签安静地放在下方；文字可换行，长内容与大字体不裁切。
- 每人一条当前便签，最多 120 个字符，新便签替换自己的旧便签；支持编辑、删除确认与撤销。
- 草稿在关闭弹层、切换页面和正常应用重启后可恢复。按账号和使用模式隔离，不能串到别的账号或对方。
- 保存失败保留输入，不能假报成功。删除与撤销要接入真实持久化/同步，明确操作结果；不能只撤销 UI，却让服务端继续保持删除。撤销不得覆盖随后新写的留言。
- 空白与超长输入有准确提示；字符计数与服务端一致，覆盖中文、换行及 emoji，不按 UTF-16 单元随意截断。
- 不增加聊天记录、已读、催回复、在线时长或自动回信。

### 我的节奏

- 工作日/休息日分段切换、一天概览、活动列表及独立的联系偏好区域，遵循当前设计。
- 保留现有合理的活动增删、命名、分类、时间编辑、学生/上班族模板等业务能力，用新版视觉承载，不能因为设计稿是简化例子而删掉功能。
- 跨午夜睡眠、活动重叠、无效时间、联系偏好与睡眠冲突按现有正式规则验证；未安排的时间保持未知。
- 保存后首页、一天和共同窗口一致更新；失败保留输入。临时状态不覆盖用户长期模板。

### 邀请、配对、资料与设置

- 沿用邀请票券、共享说明、独立接受步骤和清晰确认层级，接入真实邀请码、有效期、复制/分享、接受、撤销、重建与等待状态。
- 等待配对时不出现虚构伙伴；配对成功但对方未填作息时保持未知。
- 昵称和城市必须能真实编辑，不能保留设计稿中的只读示例。手动选城市/时区，不要求定位。
- 暂停/恢复分享、解除配对使用明确状态与必要确认。解除后保留自己的节奏，停止显示对方资料，关闭相关详情并处理旧缓存。
- 邮箱登录、OTP、首次设置、会话失效等未完整绘制的页面，也必须迁移到同一设计系统，不能留下显眼的旧风格入口。
- 品牌展示可用于简洁的关于页；设计注解、素材下载和评审工具不应直接成为正式软件主流程。

## 5. Logo 和图标必须使用已确认素材

新标记为相接的 n/u：夜蓝与晨光两条圆角曲线，中间青色共用一笔。直接复用提供的矢量路径，不重新创作，不用文字字符、emoji、默认图库图标或相似形状代替。

- 完整 Logo：`brand/logo.svg`；单色/深底用对应 mono/reverse 版本。
- 独立标记：`brand/mark.svg` 及对应变体。
- 页面图标：`brand/icons/`，24 网格、1.8 描边、圆角端点；此刻为 n/u、一天为并行轨道、留话为折角便签。
- 应用图标：使用提供的自适应前景和夜蓝背景，正确接入 Android launcher、round icon、启动画面及必要兼容资源；适用系统的单色主题图标保持同一轮廓。
- SVG 转 Compose ImageVector/VectorDrawable 时核对路径、颜色、视口、透明度与安全区。已有 XML 只是导出候选，必须通过实际编译与显示验证。
- 展示 PNG 自带圆角，不要把它当自适应图标前景再套一层圆角背景。检查圆形和其他系统蒙版下不裁切、不双重缩小。
- 保持比例和留白，不随意改字标、拉伸或追加阴影描边。生产可达页面不再使用旧 Logo 与旧图标。

## 6. 正式业务不能照搬演示数据

设计稿固定的 2026-10-03、北京/纽约、小满/阿远、NU-824619、示例留言、切换情境与“重试演示连接”只用于设计评审，不能写入真实账号路径。

设计稿的刷新重置、模拟配对成功、模拟恢复网络、只读资料页、localStorage 及简化时间引擎也不是正式软件行为。真实账号使用真实时间、服务端身份和数据、可靠持久化、真实错误反馈；本地体验保持独立且标明，不上传演示资料。

时间计算统一来自可测试的业务层，覆盖 IANA 时区、夏令时、半小时/45 分钟偏移、跨午夜、双方当地工作日/休息日和未来七天窗口。当前活动、临时状态、联系意愿和共享权限是不同概念，不能混为“在线/有空”。

未知与七天无交集分别显示；离线数据注明最后成功更新时间。暂停或解除分享后不得继续展示无权限的伙伴活动或留言，即使某个设计示例仍保留样例时钟，也以正式权限规则为准。

保留邮箱 OTP、独立账号/会话隔离、配对访问控制和第三账号拒绝。新增字段时提供兼容和迁移，不通过清空用户数据解决兼容问题。修改后端只限实现这些需求所必需的范围。

至少验证：

1. Android 构建、相关单元测试、主要 Compose 流程测试；根据现有环境运行 Gradle wrapper，不能用网页测试代替 Android 验证。
